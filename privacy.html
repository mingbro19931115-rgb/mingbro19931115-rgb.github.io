隱私權政策（Privacy Policy）

最後更新：2026 年 11 月 18 日

「Ming 影片產線」（以下稱本工具）是 YouTube 頻道「Crypto_玄學交易員Ming」的擁有者，為了管理自己的頻道而寫的內部工具。本工具不對外開放，唯一的使用者是頻道擁有者本人。

1. 本工具會存取哪些資料

透過 Google OAuth，經頻道擁有者本人同意後，本工具會使用下列 YouTube API 權限：

  • youtube.upload：把頻道擁有者自己製作的影片上傳到他自己的頻道，並設定標題、說明、縮圖與預約公開時間。
  • youtube.readonly：讀取自己頻道的影片清單與上傳狀態，用來確認上傳是否成功。
  • yt-analytics.readonly：讀取自己頻道的觀看與訂閱數據，用來檢討影片成效。

2. 資料怎麼使用、存在哪裡

  • 授權憑證（OAuth token）只存在頻道擁有者自己的電腦上，不上傳到任何伺服器。
  • 從 YouTube 讀到的資料只用於上述用途，保存在頻道擁有者自己的電腦上。
  • 本工具不蒐集其他使用者或觀眾的個人資料。

3. 資料分享

本工具不會把任何從 Google／YouTube 取得的資料出售、出租或分享給第三方，也不用於廣告。

4. 撤銷授權與刪除資料

頻道擁有者可以隨時到 Google 帳戶的「第三方應用程式」頁面撤銷本工具的存取權，並刪除本機的授權檔，所有存取立即停止。

5. 使用 Google API 的規範

本工具使用 YouTube API 服務，遵守 YouTube 服務條款與 Google 隱私權政策。本工具對 Google API 資料的使用，遵守 Google API Services User Data Policy，包括「有限使用」（Limited Use）的規定。

Privacy Policy (English)

"Ming Video Pipeline" is an internal tool used only by the owner of the YouTube channel "Crypto_玄學交易員Ming" to manage his own channel. It is not offered to the public.

With the channel owner's consent via Google OAuth, it uses the scopes youtube.upload (upload the owner's own videos to his own channel and set title, description, thumbnail and scheduled publish time), youtube.readonly (read the owner's own video list and upload status to confirm uploads) and yt-analytics.readonly (read the owner's own channel statistics).

OAuth tokens and any data retrieved are stored only on the channel owner's own computer. No data is sold, rented or shared with third parties, and none is used for advertising. No data about other users or viewers is collected.

Access can be revoked at any time at Google Account → Third-party apps. This tool uses YouTube API Services and complies with the YouTube Terms of Service, the Google Privacy Policy and the Google API Services User Data Policy, including the Limited Use requirements.
